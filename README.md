# AlderFlow Drainage & Infrastructure

A polished, responsive landing-page concept for an Irish drainage and infrastructure contractor. It separates urgent residential enquiries from commercial and civil work, keeps contact actions visible on mobile, and demonstrates the structure needed for DNS and Microsoft 365 handoff.

## What is included

- Responsive single-page layout
- Emergency drainage and commercial infrastructure service paths
- Accessible navigation and clear conversion points
- Mobile call bar and WhatsApp-style contact action
- Safe demo interactions that never contact a real business
- Embedded favicon and no external runtime dependencies

## Preview

Serve the dist directory with any static web server. For example:

    python -m http.server 4173 --directory dist

Then open http://localhost:4173.

## Production handoff

This is an independent portfolio concept for a fictional service brand. Before a client launch, replace the demo telephone, email, service coverage, credentials, and legal details with verified business information. Connect the domain only after DNS records and Microsoft 365 mail records have been documented and approved.
